# Support Ticket System — Frontend Client

Cliente web desarrollado con **React 19**, **TypeScript**, **Vite**, **Tailwind CSS** y **Zustand** para el Sistema de Soporte de Tickets con IA.

Para levantar todo el proyecto completo (Base de datos PostgreSQL + Backend .NET + Frontend React), ejecuta desde la carpeta raíz del repositorio:

```bash
docker-compose up -d --build
```

Consulta el archivo [`README.md` principal](../../README.md) en la raíz del proyecto para ver las credenciales de Administrador y Usuario de prueba y el detalle completo de la arquitectura.
